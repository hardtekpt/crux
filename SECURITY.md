# Security

Crux keeps all data on the phone and has no server, but bugs that could expose that data still
matter: backup import, the file provider, or anything another app could reach.

## Reporting a vulnerability

Please report it privately through GitHub:
[**Report a vulnerability**](https://github.com/hardtekpt/crux/security/advisories/new)
(the Security tab, then *Report a vulnerability*). Don't open a public issue for it.

Include what an attacker could do, the steps to reproduce, and the Crux version
(*Settings → Diagnostics* shows it in a crash report, or see *App info* on the phone).
You'll get an answer within a week. Fixes ship in a patch release, and the advisory is
published once the fixed release is out.

## Supported versions

Only the latest release gets fixes. Updating keeps your data.
